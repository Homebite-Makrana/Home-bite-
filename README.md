# Home Bite – Makrana v1
Full-stack starter for a local food delivery marketplace.

Included:
- Customer web app
- Customer registration/login
- Restaurant + home-kitchen discovery
- Menu and cart
- Order creation + order history
- Admin dashboard
- Add/manage restaurants and home kitchens
- Restaurant partner login/panel
- Delivery partner login/panel
- SQLite database for development
- Role-based API authorization

Demo accounts:
Admin: 9999999999 / admin123
Restaurant: 9000000001 / restaurant123
Delivery: 9000000003 / delivery123

Run:
npm install
npm start

Then open http://localhost:3000

Before public launch:
- change all demo passwords
- set JWT_SECRET
- use a production DB
- add OTP/SMS
- add payment gateway
- add maps/GPS
- add push notifications
- deploy backend and build/sign Android app
